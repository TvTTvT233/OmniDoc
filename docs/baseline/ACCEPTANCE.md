日期：2026-10-14。协调与最终验收在主对话；执行由子 Agent 分工完成。

## 范围与起点

- 基线：`integration/core-baseline`，起始提交 `ca3423a73bc7bc15190978989e2105b30298a558`。
- 起始未提交变更：`docs/PROGRESS.md` 中上一轮现状分析记录，保留原文。
- 本轮目标：可复现启动说明、当前环境实际状态、自动回归、真实服务主流程、消除旧编辑器失败后展示成功示例的行为。
- 不纳入：Review M0 合入、新专业场景、文档自动索引架构、任务平台重构、发布或远端推送。
- `main` 保持原引用，直到候选具备明确验收结论后再决策。
- 用户补充范围：本轮先验证无需外部模型的部分。B06 的真实 Embedding/生成、B08 的真实 Tavily 调用，以及 B07 的真实模型规划/回答不纳入本轮通过要求；明确标记“本轮未验证”，不能写为已验证。B07 仍覆盖可独立运行的会话持久化/API 与无模型配置下的真实失败反馈。

## 证据等级

1. 源码检查：只说明逻辑存在。
2. 确定性自动验证：记录替身和占位配置，不说明真实外部服务可用。
3. 真实依赖/API 验证：记录具体依赖、隔离资源、请求结果与持久化结果。
4. 真实浏览器验证：实际操作并检查 UI 状态与请求效果。

同一能力可以有多个等级的证据。未执行、被阻塞和执行失败分别列出；不能把跳过项算为通过，也不能以关闭核心能力的启动替代完整启动通过。

## 验收项目

| 编号 | 验收对象 | 通过依据 |
| --- | --- | --- |
| B01 | 版本、配置与启动说明 | 明确工具与基础服务版本、启动顺序、迁移、端口、环境变量名称、启动/停止方法；不包含真实凭据 |
| B02 | 后端回归与构建 | 适用已有门禁及构建实际执行；记录发现/通过/失败/跳过计数，保留失败与修复证据 |
| B03 | 前端回归与构建 | 已有适用测试与生产构建通过；分析/索引失败不生成成功示例，不丢失文档正文，成功流程保持兼容 |
| B04 | 基础服务与应用启动 | 真实依赖健康与应用状态实测；说明哪些模块未启动及原因，不能仅以进程存在判断可用 |
| B05 | 身份与文档主流程 | 隔离样例的注册/登录、上传、文档创建、读取、修改保存及重新读取，检查数据确实持久化 |
| B06 | 知识问答 | 真实 Embedding 完成索引，真实模型回答并返回来源；说明向量模式、降级与范围；替身单列 |
| B07 | Agent 与会话 | 请求完成、工具调用或明确错误；会话消息持久化；重新加载可恢复历史，不能推断执行中任务恢复 |
| B08 | MCP | 明确关闭/未配置/失败/成功；真实外部 MCP 需真实请求证据，协议模拟测试单列 |
| B09 | 浏览器主流程 | 在真实前后端上操作关键页面，检查成功与失败反馈；API 通过不替代浏览器通过 |
| B10 | 交付与范围 | 主协调审查差异与证据；更新当前阶段与进展；记录后台资源、剩余问题和下一步 |

## 结论规则

- 自动回归通过、但真实依赖未完成：只能判定自动回归层通过。
- 依赖缺失或外部凭据缺失：记录为明确阻塞，仍完成不依赖它们的构建、修复与验证。
- 基线可启动但主流程仍失败：记录为部分通过，并列出具体失败点。
- 本轮无需外部模型的可运行基线：须有核心文档真实流程、会话可执行部分与对应前端证据；禁用或缺失模型的状态如实呈现，不能将此结论推广为完整 AI 链路通过。
- 不因历史通过、测试退出码为零、使用占位模型、构建产物生成或文档齐全而自动接受完整运行基线。

## 分工

- runtime_baseline：环境、启动与真实服务验证；运行配置、`scripts/baseline`、runtime 文档。
- backend_regression：唯一 Maven 执行者；后端测试/构建与必要最小修复，regression 文档。
- frontend_baseline：前端真实错误状态、测试/构建与前端验证，frontend 文档。
- 主协调：验收口径、证据复核、范围控制、当前状态文档和最终结论。

验证结果由后续实际执行记录补充，不预先填写通过。
