# 通用 Agent 恢复与副作用控制

起点：`integration/core-baseline / b6dab11`。用户于 2026-11-02 授权下一阶段开发。本文是实施计划，不是验收结果。

## 不变量

1. 复用 AgentExecutionService；Review 引擎和历史迁移不变。非 Agent 的旧 Async AI 不获得新的恢复承诺。
2. 新账本独立迁移、显式开关；启用后数据库不可用必须停止执行，不降级到 Redis。
3. owner + clientRequestId 标识一次提交；不同载荷同键冲突。固定计划先持久化，已完成工具结果复用，恢复保持消息标识。
4. 数据库时间租约、递增 epoch；领取、工具发送和完成均校验当前租约。租约不能撤回已经发出的远程操作。
5. 写操作发送前记账。已发送但未确定结果的操作进入 OUTCOME_UNKNOWN，禁止自动重试或借 continue/retry 绕过。只有只读工具允许有限重试。
6. 审批绑定 owner、run、step、完整已解析参数摘要；删除纳入正式审批。审批不能代替副作用幂等。
7. 不持久保存用户 JWT。后台无法获得文档服务所需授权时等待用户在前台续接，不扩大内部接口权限。
8. 前端写入为待应用动作，绑定目标文档和版本；重复结果不能重复追加。HTML PPT 的临时路径不代表可跨机器恢复。
9. 取消与会话删除阻止后续领取、提交；删除和 tombstone 在同一数据库事务中完成。

## 实施与验收

- 先实现持久账本、审批与工具重放策略，再接执行器/Async/前端。子 Agent 完成只读审计后触发额度限制，root 接手实现。
- 确定性测试：双实例领取、过期 epoch、相同提交、异载荷冲突、已完成结果复用、发送后响应丢失、审批重放和目标变化、取消/删除、计划阶段恢复和消息去重。
- 集成验证分别记录 H2、真实隔离 MySQL、生产服务与浏览器结果；不把单元测试算作真实模型或故障重启验证。
- 不调用外部模型/Embedding/Tavily，不修改用户原材料，不更新 main，不推送。

跨服务 exactly-once、人工核对后的写操作 reconciliation 接口、真实任务质量/费用评测、官方规则自动提取不在本轮承诺中。
