## 4. 人工场景

### 场景 1：短对话连续理解

1. 新建对话；
2. 输入：“我准备周五提交材料，主要检查成绩证明。”；
3. 再输入：“把刚才的时间改成下周一。”；
4. 再问：“我什么时候提交，主要检查什么？”；
5. 刷新页面后再次询问相同问题。

通过标准：回答为“下周一、成绩证明”；不继续使用被修正的周五；刷新后消息顺序和内容恢复。

### 场景 2：事实与建议不混淆

1. 告诉助手：“我已确认 GPA 为 3.8。”；
2. 让助手提出提高材料质量的建议；
3. 问：“现在已经确认的事实和仍是建议的内容分别是什么？”；
4. 再修正：“GPA 应为 3.7，刚才写错了。”；
5. 再次询问已确认事实。

通过标准：建议没有被表述为已确认事实；最终以 3.7 为当前事实，3.8 只作为已被替代的历史修正记录。

### 场景 3：长对话与滚动摘要

1. 使用交付的非敏感长对话 fixture，进行足以触发摘要的多轮对话；
2. 在早期声明一个目标、一个约束、一个待办；
3. 中间加入多条普通消息；
4. 最后分别询问早期目标、约束和待办；
5. 查看脱敏 Trace/报告中的 summaryVersion、coverage 和 token 区块统计。

通过标准：三个早期信息均能正确召回；当前消息不重复；报告 coverage 连续；界面和日志不展示完整内部摘要或敏感内容。

### 场景 4：服务重启与长期保留

1. 记录一个测试 Conversation ID；
2. 正常重启 AI 服务；
3. 重新登录并打开该对话；
4. 清理该 Conversation 的 Redis 缓存后再次打开；
5. 询问重启前已经确认的事实。

通过标准：历史和事实从 MySQL 恢复；Redis 缓存清理不会造成长期消息丢失；不得自动创建内容不同的新对话冒充恢复成功。

### 场景 5：新对话与 Runtime State 隔离

1. 在对话 A 打开合成文档 A、选中一段文字并执行一次工具；
2. 点击“新对话”；
3. 确认地址/状态使用新的 Conversation ID；
4. 在对话 B 问“刚才选中的文字和工具结果是什么？”；
5. 切回对话 A 再询问。

通过标准：B 不知道 A 的选区、文档和工具状态；A 的长期会话历史仍可恢复；前端不使用 `temp_*` 或 `default_conv`。

### 场景 6：双入口一致性

1. 分别在全局助理和编辑器聊天入口创建对话；
2. 完成两轮问答；
3. 刷新页面并查看历史；
4. 在两个入口分别点击“新对话”。

通过标准：两个入口都使用真实后端 Conversation、都能恢复历史、都创建新 ID；不存在一个入口长期保存、另一个只清 UI 的差异。

### 场景 7：跨用户隔离

1. 用户 A 创建对话并记录 ID；
2. 用户 B 尝试通过历史列表、直接 URL/API 和请求体伪造 userId 访问该 ID；
3. 用户 B 尝试追加、归档和删除；
4. 用户 A 再次读取。

通过标准：用户 B 的所有访问均失败且不泄露对话是否存在的敏感细节；用户 A 数据未被修改。

### 场景 8：归档、恢复与永久删除

1. 创建包含数轮消息和一次摘要的测试对话；
2. 归档，确认默认列表不展示或明确标记归档；
3. 恢复并继续对话；
4. 选择永久删除并确认；
5. 尝试从历史、直接 ID、缓存和搜索入口恢复。

通过标准：归档可恢复；删除后不可读取、不可继续、不可召回；自动报告的级联残留为 0。

### 场景 9：摘要模型失败降级

1. 使用验收配置让摘要模型调用明确超时或失败，不影响主回答模型；
2. 继续一段短对话；
3. 恢复摘要模型；
4. 继续对话并等待下一次摘要更新。

通过标准：失败期间主对话不损坏；旧摘要和原始消息保留；coverage 不虚假前移；恢复后可继续更新。

### 场景 10：既有能力回归

至少人工抽查：

- 普通 Direct Answer；
- 一次内部 RAG 查询；
- 一次原生工具调用；
- MCP 关闭时原生 Agent 可用；
- Qdrant 未启动时 Memory V1 仍可使用；
- 原始文档没有被会话记忆自动覆盖。

通过标准：Memory 不改变原有路由、安全审批和引用边界；未声称未实际运行的外部服务可用。

## 6. 结论规则

- 任一 P0 自动门禁失败、人工场景失败、未执行或证据缺失：保持 `MANUAL_PENDING`；
- 发现事实错误、跨用户访问、删除残留或旧 Runtime State 污染：停止验收并退回对应任务；
- 只有用户确认全部场景后，才能记录：

```text
HUMAN_ACCEPTED
```

本地、单机、合成材料与单一真实模型的人工验收，不等同于生产容量、高可用、备份灾备、全量隐私合规或多模型质量评估完成。
