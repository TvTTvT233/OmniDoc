## 保守边界

当前 Agent 持久化的工具审计消息只保留工具名和状态，不包含足以校验事实的结果正文或文档定位。因此 M05：

- 不让新的 TOOL_RESULT 单独确认事实；
- 不接受模型凭空创建新的 DOCUMENT SourceRef；
- 允许从 Assistant 来源保留 `uncertain` 等非确认状态。

这样优先避免错误长期记忆，但意味着“经工具或文档验证的 confirmed fact”需要未来独立的权威来源解析器后才能安全开放。它不应通过恢复完整工具正文、混入 Qdrant 文档 Collection 或放松校验来实现。
