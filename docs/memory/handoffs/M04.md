## 已完成

- 新增唯一 `MemoryContextBuilder`，使用按模型配置的窗口、输出预留和安全预留计算输入 token 预算。
- 按受控区块组装 System Policy、当前用户消息、Runtime State、Summary 视图、coverage 后的近期原始消息、当前 Trace 工具对和调用 payload。
- 当前消息不从历史重复注入；Tool Call/Result 以原子对裁剪；Summary 被裁剪时同时取消 coverage 边界，避免不可见的历史缺口。
- Planner、Follow-up Planner、Direct Answer、RAG Answer、Reflection、完成度评估和 Final Synthesis 全部接入同一契约。
- USER 在首次模型调用前持久化；Assistant 和脱敏 Tool Call/Result 按产生顺序追加。
- 当前消息或必要工具对超出预算时返回 `MEMORY_CONTEXT_TOO_LARGE`，保留 USER 并追加不含正文的失败 EVENT；Agent API 返回 HTTP 413 稳定错误载体。
- Trace 仅记录预算、区块 token 数、消息/工具对数和裁剪原因，Agent 起始日志不再记录完整任务正文。
