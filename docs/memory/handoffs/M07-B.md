### Readiness 边界

门禁要求 `ai-service/.../conversation/runtime/**` 中存在并可识别：

- `RuntimeState` 受控 model；
- RuntimeState Service；
- 独立 Store/Repository，或 Service 直接封装 `RedisTemplate` 的 Redis 持久化；
- 明确字段白名单；
- `Duration/expiresAt/ttl` 与实际过期调用组成的分层 TTL 语义；
- 按字段或 Conversation 执行 clear/delete/consume/remove 的接口；
- 至少一个 `*RuntimeState*Test.java` 专项测试。

门禁不为满足分层形式而强制新增无业务价值的 Store。M03-A 当前实现反馈为 Service 直接封装 `RedisTemplate`，该方式在保留 TTL、白名单和清理语义的前提下被接受。
