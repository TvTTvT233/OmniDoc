# 文档、索引与引用一致性：前端实施与验证

起点：`integration/core-baseline` / `19c61c1`。开始于 2026-10-21，自动验证更新于 2026-10-22，真实浏览器验收接续于 2026-10-26。遵循 `00-SPEC.md`，本文不是完整后端验收报告。

## 已实施

- Editor 保存提交 `expectedVersion` 与 `contentFormat: HTML`，接收实际 `version`。保存期间继续输入不会被标为全部已同步；409 冲突和其他失败保留草稿，不继续提交索引。
- 索引调用文档服务 `POST /documents/{id}/index`，只发送已保存版本与策略；不发送 DOM 正文。未保存时先保存，旧文档没有可信快照时也须显式保存。保存期间再次输入会中止后续索引操作，提醒保存最新草稿。
- 文档服务负责保存自动排队；随后显式选择策略的索引请求按已协调契约同策略幂等、不同策略替换任务。前端仅显示任务受理，不把受理当完成。
- 保存、恢复和协作接收新版本后立即失效本地旧索引状态及片段。恢复携带 `expectedVersion` 并重读实际新版本。轮询有请求代次保护，迟到的旧 READY 不覆盖更新状态；只有当前编辑版本与服务端已发布版本匹配才显示可用于问答。
- GET 分段读取必须有 `documentVersion/generationId` 且匹配当前 READY 状态才显示。旧数组或无版本片段不能证明当前来源，显示结果未知；无当前 active 分段时提示以上方索引状态为准，不把 QUEUED/FAILED 错说成从未索引。
- Dashboard 正常列表与搜索均读取真实索引状态，不再用摘要存在判定“AI已就绪”。状态请求失败显示未知。
- 解析状态与索引状态区分：解析失败为 `FAILED/PARSE_FAILED`，合法空文本为 `DISABLED/EMPTY_CONTENT`，没有新造 indexState 枚举。解析失败可显式重试原文件解析；有未保存草稿时禁止该操作覆盖草稿。PLAIN_TEXT 原文仅转义和保留换行，不通过 AI Markdown 清洗改写原文。
- 协作自动保存复用 Editor 的 CAS 保存入口；轮询使用统一文档 API，错误不再变成空正文。远端修改遇到本地草稿时暂停替换并告知，不扩展为完整协作合并算法。
- `references` 从公共 Conversation 消息白名单进入聊天映射。Editor 文档侧栏、chat-mode、全局助理和 Agent Workbench 即时/任务历史结果共享只读引用组件。旧消息没有引用保持空数组，不从模型正文构造引用。
- 引用点击后调用受保护的 resolve API，验证文档/版本/引用标识、范围、片段 hash 与 CURRENT/HISTORICAL 一致；正文以纯文本展示，明确历史版本。不跳到当前编辑正文、不生成页码或坐标。错误或新请求清除旧面板内容；关闭面板后的迟到响应不会重新打开它。

全局 RAG 范围保持原有含义；没有扩展 Review 场景、模型选择逻辑或协作系统。后端版本发布与访问权限才是最终权威，前端状态不能代替后端检索闸门。
