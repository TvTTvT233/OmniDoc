## 冻结决策

| 决策 | 结果 | 原因 |
| --- | --- | --- |
| SDK | MCP Java SDK 2.0.0 | 当前 GA，覆盖 2025-11-25 规范 |
| JSON | Jackson 2 模块 | 与 Spring Boot 3.2 当前栈兼容 |
| Transport | Streamable HTTP | 新版协议主路径，适合远程服务 |
| Client API | Sync | 与当前 MVC/阻塞式执行器一致 |
| Spring AI | 不升级 | 避免把 MCP MVP 扩大成框架迁移 |

| 重试 | 复用 Agent 层 | 避免连接层和 Agent 层重复重试 |
| 密钥 | 环境变量 + Header | 避免 URL、日志和版本库泄漏 |
