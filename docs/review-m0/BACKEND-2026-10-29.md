## 修改与边界

- `ReviewM0ApiDtos/Service/Controller`：增加按登录 owner 隔离的 `GET /api/review-m0/cases`。limit 默认 20、范围 1–100；按 created_at、case_id 倒序，使用严格 canonical base64url caseId 游标；游标必须属于当前 owner。未知 userId 查询参数不能切换身份。响应为 items/nextCursor。
- `ChecklistService`：草稿读取投影始终取最新 revision（可为 CONFIRMED），保留停用项目；发布必须基于最新 CANDIDATE_DRAFT，避免旧候选复活。发布后可从最新 revision 编辑。
- `HttpOwnedFileByteSource/ReviewM0Configuration` 与 file-service 的 `InternalReviewFileAuthenticationFilter/InternalReviewFileController`：无用户请求上下文的后台任务使用独立只读服务通道，逐次核验 owner/fileId。配置名 `OMNIDOC_REVIEW_INTERNAL_TOKEN`；空值或不足 32 字节禁用；不保存用户 JWT。存在公开请求或用户认证上下文时仍使用原 JWT 验证，不能退回内部凭据绕过身份检查。
- 内部路径 `/internal/review-files/{fileId}/metadata|content` 仅 GET；凭据错误 401、缺少/非法 owner 400、越权文件 404；不经网关公开路由。内容复用既有完整性校验与流式读取。
- file-service `application.yml/application-local.yml`：MyBatis 默认 NoLoggingImpl，避免 SQL 结果打印 hash、存储定位等。`MyBatisRuntimeLoggingTest` 实际捕获 H2/MyBatis 查询输出，含旧 StdOutImpl 的敏感性对照。
- `ReviewM0JobPoller`：补齐生产自动领取队列的生命周期，复用既有 dispatcher，单线程每秒最多启动一个任务；随机 workerId、持久化开关、错误后继续、停机关闭。不重复创建 dispatcher 的取消恢复线程。
- `ReviewM0JobDispatcher`：重复崩溃/过期租约达到最大执行次数后终止，防止无限重新执行。正式执行器仍用既有 checkpoint 延长租约；超长单阶段不会获得无限租约。
- gateway 的 Review 路由及 401 四字段错误体由主协调修改并纳入本轮构建。
- 10/30 补齐 `GET /api/files/owned?page=1&size=20` 只读已有文件列表：page 1–10000、size 1–100，裸 `items/hasMore`，复用 OwnedFileMetadataDTO；仅当前 JWT owner 的 ACTIVE 文件，按 create_time/file_id 倒序。旧无 owner 与 DELETED 数据排除，未知 owner 查询参数不能切换身份，不推断旧文件归属。
- 10/30 B 真实下载暴露 `StreamingResponseBody` 完成时的 ASYNC 再分发异常：无状态安全上下文为空而 JWT filter 默认跳过 ASYNC，导致 AccessDenied/response already committed。新增安全链回归先精确复现；common JWT filter 改为在 ASYNC 再验证原请求 Bearer，没有放行 ASYNC，也没有跳过 owner 鉴权。file/internal content 为同步 InputStreamResource，未变更内部凭据 filter。
- 10/30 浏览器继续发现带 Origin 的改名 PATCH 返回 CORS 403：common WebMvcConfig 和 gateway GlobalCorsConfig 的方法白名单均漏 PATCH。两个配置仅增加 PATCH，原 Origin/header/credential 策略不变；补预检、实际 PATCH、无效登录、跨 owner、网关未允许 Origin 的回归。此前无 Origin 的 HTTP 脚本通过不能代替这项浏览器链验证。
- 合并时保留最新文档代际与引用一致性逻辑，以及分段接口原 401 响应；`DocumentSegmentsControllerTest` 仅修正安全切片依赖，历史 parser/source 基线断言对齐最新文档创建行为。

自动候选提取仍明确不可用；没有以替身替换生产抽取，没有外部模型调用。手工添加规则是本轮主路径；不能将已挂载但未解析的官方依据冒充已确认。
